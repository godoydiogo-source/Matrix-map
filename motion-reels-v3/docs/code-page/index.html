O Claude escreve código.
Agora dirige o motion.

20 repositórios open source que ensinam o Claude Code a fazer motion graphics de verdade: 10 skills, 4 motores e 6 complementos. Aqui está o passo a passo para instalar o seu kit.

Eu não sou o autor dessas ferramentas. São projetos open source de outros autores. Eu testei, separei por categoria e deixei a lista pronta, com uma linha fiel ao README de cada um.

O que é

Motion em código, não em timeline.

Em vez de arrastar keyframes num editor, você descreve o vídeo e o Claude escreve cada frame em código (React, HTML ou JS). As skills dão a ele o ofício: easing, timing, tipografia e um loop de revisão de frames. Os motores renderizam o resultado em MP4. Os complementos trazem princípios, catálogos e bibliotecas de animação.

SKILLS · 10O ofício

Regras de motion, pipelines de Reel, filme de lançamento a partir de uma URL, edição que corta silêncio.

MOTORES · 4O render

Remotion (React), HyperFrames (HTML seekável), GSAP (timelines) e as skills oficiais do Remotion.

COMPLEMENTOS · 6A base

Princípios de motion, catálogo curado de skills, Motion.dev e o player Lottie.

Nenhuma ferramenta da lista exige After Effects. O Remotion é gratuito para pessoas e empresas pequenas; empresas maiores precisam de licença própria (veja o repositório). As demais são MIT ou licenças abertas equivalentes; confira cada README antes de uso comercial.

Passo a passo

Da pasta vazia ao Reel renderizado.

  1. 01

    Abra o Claude Code numa pasta de projeto

    Pode ser uma pasta nova. O Claude trabalha dentro dela e guarda ali as skills instaladas.

    mkdir meu-reel && cd meu-reel
claude
  2. 02

    Instale as skills da lista

    O instalador skills baixa a skill para .agents/skills/ e cria o atalho que o Claude Code lê. Comece pelas skills oficiais do Remotion e por uma skill de motion; os cards abaixo têm o comando de cada uma.

    npx skills add remotion-dev/skills
npx skills add whaleyxbt/claude-motion
npx skills add AbubakrChan/product-launch-motion
  3. 03

    Escolha o motor

    Remotion quando você quer React e um projeto que vive no tempo. HyperFrames quando quer HTML puro renderizado em MP4. GSAP entra nas timelines dos dois.

    # Remotion: cria o projeto e abre o preview
npx create-video@latest --yes --blank meu-reel-remotion
cd meu-reel-remotion && npm start

# HyperFrames: instala a skill e o CLI de render
npx skills add heygen-com/hyperframes
  4. 04

    Descreva o vídeo que você quer

    Formato, duração, o que acontece em cada cena, tom e call to action. Quanto mais concreto, melhor o primeiro corte.

    Faz um Reel 9:16, 30 s, em Remotion, apresentando o produto X.
Hook com tipografia cinética, 3 benefícios em cards, CTA no fim.
Fundo escuro, uma cor de destaque, SFX nos cortes. Renderiza o MP4.
  5. 05

    Revise pelos frames, não pelo "parece bom"

    Peça um contact sheet (um frame de cada cena) e corrija o que estiver cortado, ilegível ou fora do tempo. As skills de motion já fazem esse loop: render, inspecionar, corrigir.

    Renderiza 8 frames espalhados pelo vídeo e me mostra numa grade.
Confere texto cortado, legibilidade no celular e zona segura do Reels.
  6. 06

    Exporte no formato das redes

    1080×1920, 30 fps, H.264, yuv420p, áudio AAC 48 kHz e faststart. A skill reel-export do pack do Charlie Hills faz a checagem com ffprobe.

    npx remotion render MeuReel out/reel.mp4 --codec h264 --crf 18

O pulo do gato do vídeo: com o Product Launch Motion instalado, cole a URL do seu site e peça um filme de lançamento. A v2 é music-first (springs, cursor que conduz a ação, SFX no beat, 60 fps). A versão com narração fica em legacy/: npx skills add AbubakrChan/product-launch-motion/legacy.
